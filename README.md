# 云翔赛鸽模拟平台

真实飞行物理驱动的赛鸽赛事模拟：数千羽信鸽从放飞点同时开笼，按风场、移动雨区、地形高程与自身体力飞回各自鸽舍，成绩以经纬度大圆距离和鸽钟到钟时刻核算分速。全部过程在 Canvas 上可视化。

## 快速开始

```bash
npm install
npm run dev        # 本地开发，自动打开浏览器
npm test           # 引擎单元测试（38 项）
npm run perf       # 5000 羽 / 500km 性能压测（指标 < 10s）
npm run build      # 类型检查 + 生产构建
```

## 五项需求的实现位置

| 需求 | 实现 |
| --- | --- |
| 真实模拟飞行，风场/天气/地形/体力，鸽舍距离各异 | `src/engine/simulator.ts` + `physics.ts`，鸽舍经纬度由 `scenario.ts` 确定性生成 |
| 大圆距离 + 鸽钟分速，误差 < 1 秒 | `geo.ts` Haversine；到钟在 60s 步长内做线段-判定圆插值（亚秒级），`scoring.ts` 核算米/分 |
| 中途变天，移动逆风带/降雨区，遇雨落地或绕飞 | `wind.ts`（高斯剖面移动逆风带）、`weather.ts`（生消移动的椭圆雨团）；个体按 `rainTol` 分化 |
| 5000 羽 / 500km ≤ 10 秒；结群飞行、近家分道 | 群为模拟实体（O(群数) 物理计算），空间哈希合并，35km 分道圈逐羽脱离；实测约 **1.2 秒** |
| 赛事列表 / 报名 / 成绩公示三页 + Canvas 航迹 | `src/ui/pages/`，hash 路由；`src/render/mapView.ts` 多层 Canvas |

## 模拟模型

- **风三角**：鸽子保持空速沿期望航向飞行，风向量叠加为地速（`physics.groundVelocity`），顶不住强风时原地漂移。
- **鸽群**：开笼按巡航速度分层结群；群内共享航向与物理状态，个体保留位置抖动、疲劳与导航偏差。空间哈希定期合并相近且同速的群，群规模硬上限 220 羽防止失控。
- **分道**：鸽子距自家鸽舍 35km 时彻底离群单飞；群抵达鸽舍密集区质心附近则整体解散。
- **降雨**：雨强大于 0.25 群级绕飞（探两侧雨强选弱侧），大于 0.6 时低耐受个体落地休息至少 25 分钟，高耐受个体离群继续绕飞。
- **地形**：FBM 程序化高程栅格（双线性采样），山地触发航向规避并增加疲劳；曲流河与湖泊为水面掩膜。
- **疲劳**：随飞行时间、地形等级累积，超过阈值后空速平缓衰减（最多 18%），落地休息可恢复。
- **确定性**：mulberry32 种子随机贯穿全部生成过程，同赛事 ID 逐位可复现，测试中包含完整复现性断言。

## 目录结构

```
src/
  engine/          纯 TS 模拟引擎，无 DOM 依赖
    rng.ts         种子随机（mulberry32 + Box-Muller）
    geo.ts         Haversine 大圆距离、局部等距投影
    noise.ts       值噪声 / FBM
    terrain.ts     地形栅格、河湖水系
    wind.ts        盛行风 + 阵风 + 移动逆风带
    weather.ts     移动降雨云团
    scenario.ts    赛事目录与场景确定性生成
    physics.ts     风三角、疲劳模型
    simulator.ts   定步长模拟器、鸽群、分道、到钟插值
    scoring.ts     分速排名、团体成绩
  render/          Canvas 渲染（地形底图缓存 + 动态层）
  ui/              hash 路由与四个页面
tests/             unit / perf / smoke 三类测试
```

## 成绩规则

- 官方距离：放飞点与鸽舍经纬度的 Haversine 大圆距离，每舍不同。
- 分速 = 官方距离（米）/ 飞行用时（分），按分速降序排名。
- 16 小时未归巢记失格；另设鸽舍团体榜（本舍最快 3 羽分速之和）。
